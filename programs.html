PROJECT 01 · PYTHON

Economic Empires

Economic Empires is a turn-based economic strategy game built in Python. The project focuses on managing a nation's economy through buildings, resources, population, taxation, production, investments, and infrastructure.

About the Project

I created Economic Empires as an experiment in building a larger game system using Python. Instead of making every part of the game work independently, I designed different classes that interact with the player's overall statistics.

The player begins with a set amount of money and can use it to develop their country. Buildings can change things such as population growth, trade efficiency, production capacity, and the number of available building plots.

The game also includes different population groups with their own characteristics. Taxes can affect population weariness, while investments can change economic production and population growth.

What I Built

Economic System

A player economy that tracks money, investments, production, trade efficiency, and population growth.

Building System

Farms, factories, highways, and infrastructure affect different parts of the player's economy.

Resource Production

Resources can be assigned production slots and generate money each turn based on their production.

Population System

Different population groups have individual tax rates, happiness, populations, revenue, and weariness.

Turn-Based Gameplay

Each turn updates the country's economy and gives the player new decisions to make.
